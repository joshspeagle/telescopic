# M0 review: scaffold and random streams

**Diff:** from the first commit to 2ac3568 (scaffold, packaging, CI, docs skeleton,
`_random.py`, `warnings.py`), more than 500 lines, so four `/simplify` reviewers, one per
angle (reuse, altitude, simplification, efficiency). The `/code-review` pass runs on the
combined M0 to M2 diff after the M1 and M2 `/simplify` round (see `m1-m2.md`).

## Outcome

The streams were redesigned (spec D-8, revised in 00f9474):

- The normals and uniforms of a replicate come from two children of its generator
  (`generator.spawn(2)`), each read in order. A buffer that runs short keeps its unread
  numbers and is topped up, so no buffer width enters any number. This removes `ndim`,
  the block constant, the bypass for wide requests and its test.
- Requests gather whole windows from a strided view, with one read and one write of the
  cursors.
- The replay mode moved out of `Streams` into `testing.fixed_draws` (a subclass whose
  refill raises). `testing.random_draws` serves fresh numbers to any number of rows from
  one generator, for statistical tests; it replaced two ad hoc helpers in the tests.
- `Draws` is exported from `telescopic.kernels`, since custom kernels receive it.
- `root_seed` turns a `Generator` into the seed of four integers drawn from it (D-26).

## Findings and responses

**Reuse**
1. `database=None` in the Hypothesis profile is a no-op: removed.
2. Cursor resets in `from_arrays` were no-ops: the method is gone.
3. Compare the streams against the replicate generators directly: the property test now
   compares every row with the replicate's child generators.
4. `st.data()` for the lane position: superseded; the property test draws random lane
   orders, reassignments and buffer widths.
5. `--cov=telescopic` repeats the coverage source: CI uses `--cov`.
6. `np.array(..., ndmin=2)`: used in `fixed_draws`.
7. `sphinxcontrib-bibtex` unused: dropped.

**Altitude**
1. Buffer sizes entered every seeded number: fixed by the redesign above.
2. The fixed-array mode was a test double inside `Streams`: moved to `testing.py`.
3. No seeded way to build real draws for tests: `random_draws`, built on one generator,
   because building per-row replicate streams costs about 45 µs a row (20,000 rows: 0.9 s).
4. `Draws` was public API in a private module: re-exported from `telescopic.kernels`.

**Simplification**
1. to 4. (`from_arrays`, the `_fixed` checks, `max(ndim, 1)`): the code is gone.
5. Generators in `root_seed`: adopted (D-26).
6. to 9. Test duplication: the test file was rewritten around one property test.
10. mypy pinned to 3.12 and run twice: `python_version = "3.11"`, one run; scipy-stubs
    still installs only on Python 3.12 or newer.
11. Extensions loaded twice in `docs/conf.py`: `sphinx.ext.mathjax` dropped (HTML loads
    it). `autodoc` and `autosummary` stay listed, because the API pages use their
    directives and configuration directly.
12. `sphinxcontrib-bibtex`: dropped (reuse 7).
13. `html_static_path` pointing at an empty directory: dropped with the directory.
14. Small no-ops: done, except that `"reports"` is replaced in the ruff exclusions by
    `notes/reviews/scripts`, the archived reviewer scripts.
- Two mutants survived the old tests (only the first row's cursor advancing; `assign`
  not resetting cursors). The new property test checks every row and reassigns lanes.
- The duplicated `couplings._log_uniform` goes to the M1 review.

**Efficiency**
1. The 2-D gather and the repeated cursor reads: replaced by the window gather.
2. The 1.5× target was not met: the target is restated in absolute terms (spec §10).
   `uniform(k)` was not adopted: −8% at 256 lanes does not justify a second request form.
3. Buffer discarded on reassignment: widths are now free, so the default width was
   chosen by measurement (below).
4. `replicate_generator` costs 11.7 µs: counted in the setup cost below.
5. CI time is dominated by pip: not changed. The wall time is about 1 minute, and
   `setup-uv` would be a new third-party action for little gain.

## Measurements

Commit 00f9474 plus this change; Intel Xeon @ 2.10 GHz, 4 cores; one thread
(`threadpool_limits(1)`); Python 3.13.16, NumPy 2.5.4, SciPy 1.18.1. A step is
`normal(10)` plus two `uniform()` for 256 lanes, with each lane reassigned after a
random number of steps; the best of three runs. Script:
`notes/reviews/scripts/m0/bench_streams.py`.

| Buffer width | 97 to 127 steps per replicate | 1400 to 1600 steps |
|---|---|---|
| 128 | 0.552 µs per lane-step | 0.433 |
| 256 | 0.458 | 0.357 |
| 512 (default) | 0.478 | 0.328 |
| 1024 | 0.517 | 0.309 |
| 2048 | 0.612 | 0.313 |

One shared generator: 0.148 µs per lane-step. Setting up a replicate's three generators
and assigning its lane: 44.6 µs. Normals dominate: `standard_normal` costs 14 µs per
1024 values here, `random` 2.8 µs.
